# Tax-calculator
a calculator for your taxes, it also tells you if you need to file according to irs.gov if your in america


REQUIREMENTS
---------------------------
PYTHON 3.7 or later <a href="https://www.python.org/downloads/">download</a>


HOW TO USE
---------------------------------------
1. install python 3.7 or later from the embedded link above

2. once installed download tax_calculator.py

3. double click to open tax_calculator.py or in a command prompt where tax_calculator.py is located run python tax_calculator.py
